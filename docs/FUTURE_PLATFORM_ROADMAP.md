# Future platforms

Linux x86_64 remains an active implementation and regression target. Android
development was explicitly approved on 2026-11-28. Windows is still deferred;
the presence of its runner is not evidence of support.

## Windows — after Linux stable and a separate user decision

Review Flutter Windows runner, Rust native libraries, existing SMTC integration,
Windows packaging, data compatibility and Windows-specific QA.

## Android — active development

See [Android build and testing](ANDROID_BUILD_AND_TESTING.md) for prerequisites,
verification scope, outstanding device acceptance and APK/AAB commands.

This document is a roadmap only. Windows remains outside the current scope.
