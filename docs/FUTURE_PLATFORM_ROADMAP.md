# Future platforms

Linux x86_64 is the only active implementation and acceptance target.
Existing Windows/Android code is retained; its presence is not support evidence.
No new platform starts automatically when a Linux checkpoint finishes.

## Windows — after Linux stable and a separate user decision

Review Flutter Windows runner, Rust native libraries, existing SMTC integration,
Windows packaging, data compatibility and Windows-specific QA.

## Android — after separate approval

Review Flutter Android UI, existing MediaSession/foreground playback adapters,
lifecycle, secure storage, ABI compatibility, APK/AAB packaging and device QA.

This document is a roadmap only. Neither platform belongs to the unfinished
Linux feature checklist.
